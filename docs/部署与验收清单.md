## 二、阻塞点：云函数部署失败

### 现象

```
$ cli cloud functions deploy --env cloud1-d4ge4gu1le8fe61d3 --names auth --remote-npm-install
✖ [auth] upload cloud function auth - deploy
[error] getCloudAPISignedHeader failed:
        {"base_resp":{"ret":41002,"errmsg":"system error."}}
```

重试结果相同，不是偶发。环境本身可以列出（`cloud env list` 正常），但**无法在其中创建云函数**。

### 旁证

排查时观察到三个现象，指向同一个方向：

1. 云开发控制台标题显示 **`cloud1 免费开发环境`**
2. 控制台打开着 **购买弹窗**：个人版 ¥19.9/月，开始 2026-09-15，到期 **2026-10-15**
3. 支付页窗口显示 **`pay.qq.com 意外终止了连接 ERR_CONNECTION_CLOSED`**

### 需要你做

1. **确认套餐是否已支付成功。** 如果购买弹窗只是填好了还没点「购买」，环境可能仍处于受限状态，无法创建资源。
2. **打开「自动续费」。** 这次故障的根因就是环境到期未续——控制台里 `自动续费` 目前是关闭的。不开的话 **2026-10-15 会再次失效**，同样的问题会重演。
3. **评估是否开启「按量付费」。** 目前也是关闭的。关闭状态下配额用尽服务会直接不可用；开启后超额部分按量计费。商用建议开启。
4. 若支付页一直打不开，检查本机网络/代理（`ERR_CONNECTION_CLOSED` 是连接被中断，不是页面问题）。
5. 处理完后告诉我，我重跑部署命令并验证。

## 三、数据库集合（10 个）

**新环境里一个集合都没有**，必须先建。在「云开发控制台 → 数据库」逐个新建：

```
users              用户
projects           项目
inspections        巡查
inspection_items   巡查问题项
reports            报告
memos              待办备忘
chat_analysis      聊天整理
app_settings       公司与巡查人设置
subscriptions      订阅消息授权
ai_tasks           AI 异步分析任务
```

### 建议创建的索引

新建集合后默认无索引，列表查询会随数据增长变慢，且云开发单次查询默认只返回 100 行，**超出部分会被静默截断**（看板计数会偏小）。建议按下表建索引：

| 集合 | 索引字段 | 说明 |
|---|---|---|
| `users` | `openId` | 唯一索引 |
| `app_settings` | `openId` | 唯一索引 |
| `projects` | `ownerOpenId` + `deleted` + `updatedAt` | 项目列表 |
| `inspections` | `projectId` + `deleted` + `createdAt` | 项目内巡查列表 |
| `inspections` | `inspectorOpenId` + `deleted` + `createdAt` | 我的巡查 |
| `inspection_items` | `inspectionId` + `deleted` + `sortOrder` | 巡查详情 |
| `inspection_items` | `projectId` + `deleted` | 项目问题统计 |
| `reports` | `projectId` + `deleted` + `generatedAt` | 报告列表 |
| `reports` | `inspectionId` + `deleted` | 按巡查查报告 |
| `memos` | `createdBy` + `deleted` + `createdAt` | 待办列表 |
| `subscriptions` | `openId` + `scene` | 授权查询 |
| `ai_tasks` | `status` + `createdAt` | 任务调度 |

> 数据库权限建议全部选 **「仅管理端可读写」**。所有读写都经云函数，前端不直连数据库。

## 五、环境变量

在「云开发控制台 → 云函数 → 选中函数 → 配置 → 环境变量」中设置。

### `speech`（语音转文字，必需）

| 变量 | 说明 |
|---|---|
| `SPEECH_SECRET_ID` | 腾讯云 SecretId |
| `SPEECH_SECRET_KEY` | 腾讯云 SecretKey |
| `SPEECH_REGION` | 可选，默认 `ap-guangzhou` |

还需在腾讯云控制台**开通语音识别 ASR 服务**，否则会报 `FailedOperation.UserNotRegistered`。

### `ai`（图片问题识别，必需）

二选一：

**方案 1 · 腾讯混元**

| 变量 | 说明 |
|---|---|
| `AI_SECRET_ID` | 腾讯云 SecretId |
| `AI_SECRET_KEY` | 腾讯云 SecretKey |
| `AI_REGION` | 可选，默认 `ap-guangzhou` |
| `AI_MODEL` | 默认 `hunyuan-lite` |

> 注意：混元路径**不支持图片识别**（代码里走的是纯文本 `ChatCompletions`）。要做图片识别请用方案 2。

**方案 2 · OpenAI 兼容接口（支持多模态，推荐）**

| 变量 | 说明 |
|---|---|
| `AI_API_KEY` | 服务商 API Key |
| `AI_BASE_URL` | 例如 `https://open.bigmodel.cn/api/paas/v4` |
| `AI_MODEL` | 例如 `glm-4.6v` |
| `AI_PROVIDER` | 可选，填 `zhipu` 时会带上 thinking 参数 |
| `AI_THINKING` | 可选，`enabled` / `disabled` |

### `report`（PDF 出图，必需）

| 变量 | 说明 |
|---|---|
| `PDF_SERVICE_URLS` | PDF 服务地址，例如 `https://pdf.haolizhiguan.cn` |
| `PDF_API_KEY` | 与 PDF 服务端 `PDF_API_KEY` 保持一致 |

## 六、PDF 服务

改动后**未配置 `PDF_API_KEY` 会直接拒绝启动**（原先是放行，等于对公网开放）。

```bash
cd report-pdf-service
PDF_API_KEY=<你的密钥> npm start
```

可选环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3100` | 监听端口 |
| `PDF_ALLOWED_IMAGE_HOSTS` | 空 | 追加允许的图片域名后缀，逗号分隔 |
| `PDF_ALLOW_HTTP` | `false` | 本地调试时可设为 `true` 放行 http |
| `PDF_TASK_TTL_MS` | `1800000` | 任务与临时文件保留时长 |
| `PDF_TASK_SWEEP_INTERVAL_MS` | `300000` | 清理扫描间隔 |

默认放行的图片域名：`.tcb.qcloud.la`（微信云存储）、`.myqcloud.com`（腾讯云 COS）、`.haolizhiguan.cn`。
`file://`、`localhost`、内网 IP、云元数据地址（`169.254.169.254`）一律拒绝。

## 七、验收清单

部署完成后按顺序验证：

### 基础连通

- [ ] 打开小程序，**不再出现「云环境不可用」弹窗**
- [ ] 控制台无 `Env Not Exists` 报错

### 主链路

- [ ] 新建项目 → 填名称和地址 → 保存 → **有「保存中」提示，成功后列表出现该项目**

- [ ] 报告页生成 PDF（需 PDF 服务与密钥）
