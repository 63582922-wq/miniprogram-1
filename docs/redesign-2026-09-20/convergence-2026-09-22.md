# 主链路与界面体系重新收敛 · 执行记录

## 需求理解与边界
现场人员需要的是可信的项目归档和可交付的单份报告，不是有配色的页面集合。先保证项目、账号、会话不会串，再让导航、资料维护和报告形成一个系统。视觉调整为“现场记录册”：暖纸色、中性墨黑、朱砂橙、照片优先；正式产品不再保留墨绿色相。项目只承担归属，不引入施工阶段、负责人、进度或任务管理。三栏导航取代旧四栏建议。已有数据、草稿和已发布报告不得批量覆盖。

## 已确认实施顺序
1. 复现与修复项目入口、草稿归属、身份等待和加载竞态。
2. 交互母版和状态规格：紧凑项目首页、项目详情、记录核对、三栏导航、我的资料与报告交付。
3. 映射正式小程序，恢复公司 LOGO、公司和巡查人资料入口；单报告分享必须携带该报告的确认资料。
4. 自动回归 + 正式运行点击和截图；跨项目、身份异常、分享与重开分别记证据。
5. 真机体验版。iOS/Android、接收方和公网 PDF 未实际验证不得标通过。

## 修复前代码证据
- 采集页优先恢复全局 latestInspectionDraftMeta，覆盖新项目入口；项目加载还会默认选第一项。
- 全局 pendingPhotos 没有项目或会话归属。

- 拍照在四栏组件中永久高亮，业务新建操作挤在胶囊所在标题行。
