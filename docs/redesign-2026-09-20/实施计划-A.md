## 目标与边界

只把一条垂直链路做到可靠、易用、交付清楚：

**项目 → 现场照片 → 人工文字/语音说明或自选 AI 识图 → 精准标注 → 人工核对 → 在线报告 → 微信只读转发。**

- 产品是现场质量记录与报告工具，不做施工管理、整改闭环、待办或团队协作。
- 人工提供事实并最终确认；AI 可整理文字字段（区域、分类、责任方等）或按用户选择分析照片。无依据的字段留空，不猜；零问题照片保留，不等于验收合格。
- 唯一交付物是保存在**微信云开发（CloudBase）数据库/云存储**中的在线报告，由现有云函数负责发布、权限校验和只读分享，微信内阅读和转发。为此仍需要托管云数据库、云存储和云函数，但**不需要单独购买或维护 Ubuntu/VPS 来生成 PDF**。**不生成 PDF，不测试 PDF 文件/服务/排版**；历史 PDF 代码可暂存，但不进入产品路径、执行计划和验收门槛。网站域名的 ICP/公安备案是网站合规事项，不等同于小程序云后端，也不是当前在线报告链路的替代方案。
- 保留原生小程序、现有云服务、历史数据、照片分组及照片内问题编号。只用隔离 QA 数据；未经明确授权不部署、不发布、不发送给外部接收者。

## 产品与 UI 总合同

UI 体系是全局规则，不是统一换色或给每页套卡片。每个正式页面都按同一合同落地：

- **视觉基线：**暖纸 `#E9E4DD`、墨色 `#191816`、朱橙 `#DE6E3F`；轻、安静、精确，不用玻璃/塑料质感，不大面积铺色。
- **排版：**系统无衬线为操作与正文；固定字号/字重阶梯、行高、8rpx 间距基准、页面边距与安全区。标签和值分层，不让文字和图标错基线，窄屏按钮文案不意外折行。
- **组件：**图标来自统一本地资产，语义、尺寸、线宽、颜色一致；按钮统一触控高度、图文间距与主次态；对象可用克制容器，照片/说明/问题采用连续内容与轻分隔，不层层套卡。
- **交互：**每屏一个主操作；按下、录制、上传、识图、保存、发布均有清楚状态。空、加载、错误、成功不能混淆；错误有恢复动作。动效不延迟手势。
- **页面职责：**项目负责选择与进入；采集负责照片和说明；标注负责在照片上定位；核对负责逐照片确认；报告负责手机阅读与转发；“我的”负责巡查人和公司/Logo资料。每页按需展示信息，不重复解释。

## 执行与验收责任边界

- **开发侧（我负责）：**继续完成本地客户端与云函数代码、数据可靠性、AI/文字结果可见性、全局页面及报告 UI 收敛、隔离环境自动/端到端回归；交付可核对的版本差异、测试证据和部署/回退步骤。不得以用户真机验收代替代码修复，也不得擅自部署或发布。
- **使用侧（用户验收）：**真实设备、语音转文字和 AI 识图已由用户完成测试；本计划不再把这些项目列为待用户测试。具体分设备结果与 AI 样本判定仅按用户已反馈的事实记录，不从“已测”推断“全部通过”。另一微信接收/转发报告若尚无明确结果，单独记录，不与前三项混在一起。
- **停止规则：**本地问题以可复现缺陷、针对性回归和一次阶段回归收口；已经通过的同一项不重复巡检。外部验收只记录一次明确结果/设备/账号，不要求用户为同一状态反复操作。
- **外部操作闸门：**云端部署、付费 AI/语音调用、正式上传/发布仍需在操作前核对目标环境、成本和授权；未授权时完成本地准备与说明，不假称已验证线上效果。

## 上线规则与平台审核门槛（纳入本轮，不以备案通过代替）

小程序备案已由用户确认完成；它只关闭备案这一项，不代表服务类目、主体能力、隐私指引、版本审核或正式发布均已通过。当前审核中的版本不因本地改动而自动更新；若要让新代码生效，须由管理员按微信后台流程提交新版本审核，审核通过后再由用户决定是否发布。本计划不替用户点击正式发布。

### 开发侧审核清单

1. 核对 `app.json`、路由、分享、文件读写、权限请求与云调用，列出真实数据流：微信身份、项目/巡查人和企业资料、照片/标注、录音/转写、AI 文本/图片分析、在线报告只读分享；核实每类数据目的、接收方、存储位置/期限、用户删除方式和分享可见范围。隐私指引必须与实际服务端运行配置一致，不凭代码支持的“可能供应商”猜测当前供应商。
2. 把“我的”资料、照片/录音上传、报告发布/分享分别按用户主动操作设计；仅在所需功能发生时请求权限。拒绝授权时保留可用替代路径，隐私说明/服务协议可到达、可阅读，授权弹层可拒绝/关闭。
3. 核验个人主体当前已审核的服务类目是否覆盖“现场巡查记录＋AI 辅助整理＋只读在线报告”的实际功能，以及小程序名称、简介、首页入口和审核体验账号/路径是否一致。个人主体资格和类目以该 AppID 后台当前可选项及审核结论为准；不依据旧网页或备案号推断可经营范围。
4. **核验账号生命周期：**本产品采用微信身份自动识别，不新增密码/手机号注册负担；首次授权后服务端创建用户资料，后续按微信身份恢复。检查“我的”能否说明当前身份、初始化失败是否可重试、换微信账号后本地草稿是否隔离；提供便捷的个人信息权利申请受理和状态查询。注销/删除必须由运营者核验并完成删除或匿名化；不得把退出页面、软删除标记、申请收件回执或撤销分享说成已完成注销/彻底擦除。
5. 核验在线报告分享的用户可见范围、个人/企业联系信息和照片提示；接收者无需作者登录流程即可只读访问指定报告，不能读其他记录；撤销链接后在线访问失效，说明已复制/截图内容不能远程撤回。
6. 核验客户端不存在依赖未备案网站、未配置合法域名或未声明用途的必需请求；正式路径只用 CloudBase 云函数/云存储。网站域名 ICP 备案与小程序备案分开判断；此产品不嵌入网站、不开 PDF 服务作为报告入口。
7. 审核前走一遍新用户和已有用户路径：同意/拒绝隐私说明、身份失败恢复、拍照/相册权限拒绝、语音权限拒绝、无 AI 额度/识别失败、报告发布/分享/撤销、账号注销和删除路径；确认错误信息可理解，未登录或无数据不能误显示为空。
8. 分清审核版本与正式版本：体验预览、代码上传、提交审核、审核通过、正式发布是不同状态。部署云函数和设置运行环境须记录目标环境、函数版本与回退办法；不会把预览码、代码编译或备案状态写成正式上线。

- **停止/发布门槛：**若个人主体没有覆盖实际服务的有效类目，或隐私指引与 AI/ASR 的真实接收方、用途不一致，则标记为上线阻断，不用改文案掩盖主体/类目资格问题。其余视觉、交互、数据可靠性和设备验收继续推进。

## 12:39 真机反馈：六项强制验收

以下六项是本轮已确认需求，不能被“代码已改”或自动化通过替代：

1. **语音：**明显的微信式按住说话，松开转写、上滑取消；录音/转写/失败有反馈。转写内容与字段标签分开呈现，便于读懂和编辑。
2. **确认生成：**主按钮有即时按下与处理中反馈；成功进入唯一在线报告，失败明确可重试；重复点击或回包超时不重复创建。重开报告验证内容相同。
3. **AI 识图：**支持逐张选择或整批选择；显示真实进度和逐张结果/失败。用户人工描述优先，AI 仅辅助。零条结果须明确表示“未整理出可确认问题，不代表现场合格”，照片仍可手工补充。
4. **标注：**框选/圈选收敛为一个“选区”入口；选矩形或椭圆，按手势自由改比例并自动编号，编号稳定关联同照片问题。界面不提供删除、重做、撤销或微调入口；顶部返回统一负责“保存返回／继续编辑／取消本次编辑”。
5. **标注连续可见：**已保存标注在采集、核对、报告和重开时保持同一图像坐标；加载或媒体失败明确提示，不静默丢标注。
6. **整体 UI：**项目、采集、标注、核对、报告、“我的”逐页对照上述全局合同；复核文字层级、比例留白、图标、图文对齐、卡片密度、状态和安全区。需要实际运行截图与操作，不以母版或令牌测试充数。
