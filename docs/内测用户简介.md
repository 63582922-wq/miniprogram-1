## 一句话

尺包是一个微信小程序：把装修、建材、工地现场的巡查记录，做成一份能直接转发给业主或施工方的在线报告。
**拍照片 → 圈问题 → 说话或打字 → 核对 → 转发。**

---

## 一、这是什么工具

尺包是给**要跑现场、要给业主交代**的人用的——装修公司、建材商、施工队、监理。

它把一次现场巡查从头到尾收进一个微信小程序：

> 按项目拍照 → 在照片上圈出问题位置 → 语音或文字写说明 → 逐条核对 → 生成在线报告 → 微信转发。

不用下载 App，微信里打开就能用；不用手机号注册，用微信身份。
以前的组合通常是「手机相册 + 微信一条条发照片 + 事后手打 Word」，尺包把这条链路收成一条。

## 二、它解决了什么

| 以前的麻烦 | 尺包怎么做 |
|---|---|
| 照片发一堆，对方不知道说的是**哪一处** | 在照片上框选或点选，系统**自动编号**；报告里的编号和照片上的圈一一对应，点编号就看到那一处 |
| 现场手脏、光线差，**打字费劲** | 按住输入框右边的麦克风说话，松开**自动转成文字**；也可以直接打字 |
| 巡查完还要**花时间整理成报告** | 文字、语音、标注合到一起，整理成结构化条目（区域、分类、等级、责任方、建议）。AI 识图是可选的加速项，全程手动也能走完 |
| 报告**说不清轻重和责任** | 每条问题带等级（严重/较重/一般/轻微）和责任方（施工方/供应商/甲方/待确认） |
| 业主翻长报告**抓不住重点** | 报告首屏是巡查概览 + **「需要优先处理」清单**，点一下直接跳到对应照片 |
| 发出去的东西**收不回来**，也怕对方看到别的项目 | 分享的是**只读链接**：对方不用登录、看不到你其他任何记录；**随时可撤销**，旧链接立即失效 |
| 每份报告的**抬头都要重打一遍** | 公司名称、LOGO、电话、地址、巡查人和联系电话填一次，之后自动带进每份报告；报告有编号（`CB-` 开头）和出具时间 |
| 事后想找「上次那个项目记了什么」 | 一个工地一个项目，每次巡查、每份报告都归档在项目下面，项目里能看全部照片 |

## 三、可以做哪些事

| 功能 | 说明 |
|---|---|
| **项目管理** | 一个工地一个项目。只有项目名称必填，地址、联系人、电话、说明可以后补 |
| **现场记录** | 拍照或从相册选，单次最多 **20 张**；同一个项目可以记很多次（水电一次、瓦工一次） |
| **照片标注** | 在照片上框选或点选问题位置，自动编号，**编号与报告一一对应** |
| **语音 / 文字说明** | 打字，或按住麦克风说话自动转文字；两者可以一起用 |
| **AI 辅助（可选）** | 「AI 识图」整理问题描述与字段；多张照片可以「批量处理」；**结果一律标为待核对** |
| **人工核对** | 逐条确认和修改区域、分类、责任方、等级，也可以自己添加问题 |
| **在线报告** | 巡查概览、优先处理清单、照片与问题分组、整改建议 |
| **只读转发** | 生成分享链接，用微信转发给业主或施工方；可重新生成、可撤销 |
| **报告抬头** | 公司与巡查人资料，填一次自动带入 |
| **归档** | 报告列表、项目下的巡查记录与全部照片 |
| **隐私与服务** | 可提交查阅、复制、更正、删除个人信息、注销账号、撤回同意等申请，并查看处理状态 |

## 三之二、AI 能帮你做什么

AI 是**可选的帮手**，只干一件事：把照片和你说的，整理成一条条能用的条目。它不替你验收，也不下结论。不想用它，全程手动填写一样能出报告。

| AI 能力 | 具体是什么 |
|---|---|
| **AI 识图** | 找出照片里看得见的异常，写成能直接用的巡查表述（例如「门洞右侧收口边缘存在连续缺口，局部基层外露。」），并顺手填好区域、分类、等级、责任方、建议 |
| **语音转文字** | 按住麦克风说话，松开自动转文字；还会把口语整理成书面话——「厨房这块砖敲着空，声音发闷，大概三十公分」→「厨房墙面瓷砖空鼓，敲击有明显空响，范围约 30cm。」 |
| **一张照片拆成几条** | 同一张照片里只要有几个能单独整改的问题，就拆成几条，各自带编号。例如「线管弯折」和「插座底盒歪斜」会分成 2 条，不会揉成一条 |
| **越用越像你** | 记住你平时怎么改（等级、责任方、分类常调成什么），下次提醒自己注意；也会翻这个项目以前的记录，提示「这类问题以前出现过，重点看看」 |
| **批量处理** | 多张照片可以一次交给 AI 处理，不用一张张点 |

**AI 不做的四件事：**

- **不编造** —— 照片里没有证据就不写，宁可留空，也不生成凑数的问题。
- **不下结论** —— 不判合格/不合格，不推断尺寸、强度、平整度。
- **不擅自写入** —— 结果一律标「待核对」，你不点确认就不进报告。
- **不跨照片合并** —— 一张一张分开看，不会把两张照片的问题揉在一起。

> **AI 认得准不准，正是这次内测最想知道的。** 它报错了或漏了什么，你直接改掉并告诉我——你的每一次修正，都会让它下次更贴近你的习惯。

## 四、第一次用，跟着走就行

打开小程序后会**自动带你走一遍**；也可以随时从「我的 → 使用说明」再看。
真实按钮上会有高亮提示，点的是按钮本身。

1. **先填一次资料**（我的 → 设置）：公司名称、LOGO、电话、地址，以及巡查人姓名和电话。
   这些会自动进报告抬头，只做这一次。
2. **建一个项目**：一个工地一个项目，填个名称就能存。
3. **进项目 → 开始现场记录**：拍第一张照片（建议横向拍，竖图也支持）。
4. **点照片上的「标注」**：框选或点选出问题位置，自动编号，保存返回。
   这一步最容易被跳过——只在照片下写字、没有圈位置，报告里就没有编号可看。
5. **写说明，或按住说话**。想更快可以点「AI 识图」，识别结果会等你核对。
6. **点「整理说明并核对」**：逐条确认区域、分类、责任方、等级。
7. **点「确认内容并生成报告」**：打开在线巡查报告。
   有标注却没写问题的照片会被**拦下来**，避免报告缺内容就发出去。
8. **在报告里点「转发这份报告」**：生成只读链接，转发给业主或施工方。

整条链路**三分钟左右**能跑完一轮。

## 五、内测期间请你留意

先把边界说清楚，免得用起来有落差：

1. **AI 是辅助，不是结论。** 识别结果一律标成「待核对」，必须你确认才会进报告；没识别到问题时会提示「不代表现场验收合格」。
   **AI 到底准不准，正是这次内测想知道的**——请照你的专业判断直接改，改了就是在帮我。
2. **全程可以不用 AI。** 不想让照片或录音送往第三方处理，就选「仅手动填写」，流程一样完整。
3. **删除是「从列表隐藏」**（后台标记），不代表云端已彻底擦除，也不能当账号注销用。
   要注销请走「我的 → 隐私与服务说明 → 个人信息权利申请」。
4. **没写完的草稿存在当前这台手机上**，换手机看不到。
5. **分享内容不包含录音**；但对方已经保存的照片、截图或转发内容，撤销链接后也**无法收回**。
6. **之后修改公司或巡查人资料，不会改写已发布的报告。**
7. **目前报告是在线形态，没有 PDF 导出。**
8. 内测走的是微信**体验版**，可能随时更新；更新后重新打开小程序即可。
