# 毫厘智管 · 精密工程 UI 体系

本规范是正式小程序的唯一视觉与交互基线，服务于一条垂直链路：项目现场记录、照片标注、人工核对、报告阅读与转发。它不把产品扩展成施工管理或整改闭环工具。

## 设计原则

- 先让人看清现场照片与已确认的问题，再呈现 AI 建议；AI 永远不替用户确认。
- 一屏一个主动作；选填字段按需展开；照片、说明与问题按连续内容阅读，不用卡片套卡片。
- 品牌通过一致的纸色、墨色、朱橙、字阶和图标建立，不依赖大标题、装饰色块或常驻高亮导航制造存在感。
- 整体轻、安静、精确；状态变化有反馈，装饰不抢证据。

## 基础令牌

唯一来源为 `miniprogram/styles/precision-a.wxss`。业务 WXSS 引用令牌，不另设相近但不同的色值。

| 类别 | 规则 |
| --- | --- |
| 颜色 | 纸底 `#E9E4DD`，输入面 `#F2EEE8`，墨色 `#191816`，反白 `#FFF9F2`，次级文字 `#706D67`，分隔 `#C9C1B7`，朱橙 `#DE6E3F`；图标资产只使用具名语义色；朱橙只强调主操作、AI待核对和当前工具，不铺满页面 |
| 字体与字重 | 系统无衬线用于所有操作、表单、说明与数据；仅中文项目/报告对象标题可用宋体。全局只用常规 400 与中等 500 两档；标题层级优先靠字号、间距和颜色建立，不用粗字堆强调。原生按钮默认常规字重，主操作可用中等 500 |
| 字阶 | 全局只允许 7 档：显示 60rpx、标题 48rpx、对象/区块 36rpx、正文/行/统计 32rpx、操作 30rpx、辅助 27rpx、说明 26rpx。语义令牌可以不同名，但不能暗中创造近似字号。正文行高 1.5–1.7 |
| 间距 | 基准 8rpx（4 CSS px）递增；页面左右 36rpx；相邻字段 8–16rpx；内容组 24–32rpx；不为旧零碎数值保留分数令牌，安全区、照片工作区等仅保留语义尺寸 |
| 圆角 | 输入与操作 8rpx；独立对象最多 10rpx；底部动作面板 20rpx；普通内容不做悬浮塑料卡片 |
| 触控 | 命中高度统一走共享尺寸角色：44px 常规、48px 紧凑、52px 主操作、56px 核对、60px 按住语音、64px 列表行与来源选择；小图标可见图形 32–48rpx，但承载按钮仍使用对应触控角色 |
| 动效 | 状态反馈 120–220ms；标注绘制、拖动、捏合不做补间延迟；禁用和处理中必须可辨 |

## 控件合同

- **主按钮**：每屏最多一个，朱橙底、墨色字；有默认、按下、禁用、处理中态。文案用动作和结果，不用抽象“确定”。
- **次按钮**：纸底/透明底、细分隔线，仅用于并列替代动作；不得与主按钮使用相同视觉权重。
- **文字动作**：用于编辑、重试、收起等低频辅助操作，保留足够触控高度，不画成小链接。
- **图标**：只使用 `miniprogram/images/icons` 中的正式 SVG/PNG；操作含义不清时配短文字。单线图统一尺寸、圆角与视觉重心，不以字符、emoji或临时 CSS 图形代替资产。
- **字段**：标签和内容分行表达；用户文字／语音转写是原始说明，AI只负责从这段说明整理区域、分类、责任方等结构化候选，不重复识别同一照片；候选值可逐项修改并明确标明“AI整理·待核对”。核对时，若某条问题的整理描述与对应原话不同，提供默认收起的“查看原话”入口供人比对；两者相同则不重复展示。原话仅属于核对依据，不进入只读报告；空字段不制造空值标签，依据不足时留空，不猜责任方。
- **状态**：加载、空数据、无搜索结果、错误不能共用同一空态；错误需说明发生了什么和下一步恢复方式。
- **照片**：按自然比例显示完整现场；主图上的标注与同号问题一一对应。只有已保存的标注渲染图可作为带标注预览，云端 ID 必须先解析为可显示 URL。
- **页面动作唯一性**：同一动作在一屏只保留一个稳定入口。标注页顶部返回负责离开决策（保存返回／继续编辑／取消本次编辑），底部主按钮负责保存；工具栏只放照片编辑工具，不再重复“返回”。

## 全局版式合同

UI 体系不要求每页长得一模一样，而是要求相同语义在任何页面都以相同层级、对齐和反馈出现。页面可有不同内容密度，但不能自行发明字号、按钮等级或卡片语言。

### 页面骨架

- **一级页面**（项目、报告、我的）：统一产品身份区、页面任务标题、内容区和三栏导航；品牌身份克制，标题先说明“我在哪／能做什么”，不放占首屏的大型宣传文案。
- **二级任务页**（采集、标注、核对、报告详情、资料编辑）：统一微信安全区内的返回与短标题；标题不与胶囊重叠，内容区使用同一左右边距；固定底部操作为纸底承托并计入安全区。
- **页面首屏**优先露出当前对象（项目或记录）、当前阶段和唯一主动作。次级信息按需展开，不能把“项目名／记录名／照片数”在相邻区域重复说三次。
- **窄屏策略**：对象标题最多两行后按统一规则省略；左右并排只用于可比较的短信息或拍摄来源，不挤压输入、照片和长问题描述；横向滚动不作为隐藏主要操作的解决方案。

### 排版与对齐

- 页面边缘对齐到 `--a-page-inset`；同一行中的图标、文字和触控容器垂直居中，数字／状态与对应对象保持近邻，不漂到另一视觉列。
- **对象列表标题**（项目卡片名、报告列表名）共用 `object-list-title`：36rpx、常规强调字重、同一行高；不能因页面分别实现而自行漂成 34rpx 等相近字号。
- 标题、说明、字段值按“对象 → 结果／状态 → 操作”阅读；标签不能孤立在一列，按钮文字不得因固定宽度断成不自然的多行。
- 组件内部的图标与文字使用统一间隔令牌；图标按视觉中心对齐，而非只按 SVG 画布边界对齐。并列按钮等高，按钮文案基线一致。
- 长说明优先删重和按需展开，不通过持续缩小字号塞进首屏。信息完整性优先于首屏塞满。

### 容器与内容密度

- **对象容器**：仅项目、报告、草稿等能独立进入的对象使用对象容器；统一纸色表面、同一圆角、内边距和内部信息顺序。
- **连续内容**：照片、现场说明、问题和报告章节不各自套卡；按照片分组，以同一轻分隔线断章节。标注贴在照片坐标上，问题条目紧随同照片，编号必须相同。
- **表单**：标签在上、输入在下；标签只解释字段含义，不重复 placeholder。选填字段折叠时给一个可读的入口，不展示一排空字段。
- **页面动作区**：底部最多一个实心主按钮；次级动作使用描边或文字动作。拍照与相册是并列来源而不是两个“下一步”，主次差异按产品默认路径表达，不能两颗都做实心强调。
- **空态／加载／错误**：占用相同内容区域，不额外叠加无关卡片；空态给下一步，加载给当前进度，错误给可执行恢复入口。不能让空白页面看起来像加载失败。

### 图标与动态反馈

- 每个图标只能对应一个稳定动作语义；同一语义跨页面复用同一资源与尺寸。图标和文字同在时避免二者表达不同动作；没有文字时必须提供可读的辅助说明。
- 选中态只出现在当前真正被选中的对象／工具；页面导航选中由当前路由决定。不得把“拍照”永久做成选中态，也不得只靠颜色区分错误、处理中和成功。
- 按下、录音、取消录音、上传、识图、保存、发布分别有及时反馈；动画解释状态，不延迟照片手势、录音和页面主操作。
- 进入页面、返回、展开、重试与失败恢复遵循统一动作方向和按钮位置。若同类页面交互不同，必须有明确业务原因并在此规范登记。

### 关键页面模板

| 页面类型 | 固定信息顺序 | 屏内动作上限 |
| --- | --- | --- |
| 项目列表／详情 | 页面任务 → 搜索或项目身份 → 项目对象／当前草稿 → 次级历史 | 一个新建或开始记录主动作；列表筛选为次级 |
| 现场采集 | 所属项目 → 照片来源 → 新增照片后的整理方式 → 每张照片的说明／标注／AI状态 → 补充信息 | 拍照／选图是来源动作；有照片后只保留“下一步·核对”主动作 |
| 图片标注 | 当前照片 → 最大可用画布 → 选择／矩形或椭圆选区 → 撤销与保存离开 | 一个保存返回主动作；切换工具不能和保存争夺权重 |
| 人工核对 | 本次身份与数量摘要 → 按照片显示原图和对应问题 → 可编辑字段 → 本次小结 | 一个“确认内容并生成报告”主动作 |
| 在线报告 | 巡查单位与巡查人 → 项目和报告时间 → 本次概览 → 按原顺序照片及编号问题 | 分享为唯一主动作；编辑能力只属于作者且作为次级入口 |
| 我的／资料 | 账号状态 → 巡查人 → 公司与 Logo → 报告资料 → 设置与协议 | 资料行本身进入编辑；不再加重复编辑按钮组 |

这张表定义的是信息层级与动作数量，不是固定像素稿。出现新页面时，先归入页面模板；确需例外时写明业务原因，再动局部样式。

## 页面与主链路层级

1. 项目列表：一级标题、搜索、项目对象、单一新建/记录入口。
2. 现场记录：项目归属 → 拍摄/选图 → 按照片选“我来说明”或“AI识图” → 核对照片及状态 → 下一步核对。
3. 语音：微信式按住说话；松开转写，向上滑取消；权限/网络失败仍保留文字输入和原录音重试。
4. 标注：照片占最大工作区；选择、选区、箭头为主工具；选区内可切矩形/椭圆并自动编号。编号跟同照片问题稳定关联。
5. 人工核对：AI来源和待核对状态清楚；人工确认后进入发布；不能把“生成报告”点击无响应或静默吞错。
6. 报告：手机单列阅读，照片先于其对应问题，编号一致；不含产品 Logo/产品名，不渲染未填写字段，不输出分页/PDF页面装饰。

## 验收方式

- 自动：令牌存在性、图标尺寸/触控尺寸、主操作唯一性、标注 ID/编号关系、云端与本地照片预览优先级、提交反馈和失败恢复。
- 小程序编译：WXML、WXSS、页面配置和资源引用通过本地编译。
- 真机：iOS 与 Android 分别验证长按/上滑取消、系统授权、相机与相册、标注捏合拖动、底部安全区、键盘遮挡和在线报告转发。
- 未实际使用真机、云端 AI 或微信分享的项目必须明确标为未验证，不以模拟用例宣称通过。

## 实施记录（2026-09-29）

- 正式运行时项目、报告、“我的”三个一级页已做初步截图复核；列表与资料内容能加载，报告列表已呈现隔离验收记录。当前仅为开发者工具 HUAWEI Mate 60 模拟器证据，不代表 iOS/Android 真机通过。
- 页面与组件中的颜色、字号、常用间距、圆角、字重已收敛到 `precision-a.wxss`；底部操作区预留和安全区也有具名令牌。旧 `tokens.wxss` 只保留指向新令牌的兼容别名。自动测试会阻止页面/组件重新写私有颜色、字号、间距、圆角或数字字重。
- 底部导航图标统一使用仓库内 PNG，避免开发者工具 SVG 显示不稳定；选中页由单一 route 状态映射到选中图标、文字和指示条，并有导航状态测试覆盖。
- SVG 图标资源也纳入颜色系统检查：只允许墨色、辅助文字色及明确命名的反白色；禁止 `black`、`currentColor`、透明度模拟色值等会随渲染环境漂移的默认画法。
- 本轮导航复核确认项目、报告、“我的”三栏由路由状态驱动，图标资源可见且没有常驻拍照高亮；指示条细节仍需在窄屏模拟器截图中复核。长列表、报告详情和拍摄／核对页的窄屏截图仍未完成，不把未完成的视觉走查标成通过。
- 运行时复核项目和报告长列表滚动到底部，末条内容可完整露出且保留底部导航间距；路由切换到报告和“我的”后，选中态分别正确。模拟器截图另发现“我的”页原生按钮继承默认字重导致辅助资料整体过重，本轮增加统一字重令牌与按钮默认常规字重，并在模拟器热更新后复核；这仍不是 iOS/Android 真机证据。
- 后续复核发现仅新增字重令牌不足以保证全局一致：正式 WXSS 曾有 74 处直接声明 400/500/600。本轮全部改为语义令牌，并在 UI 体系测试中禁止数字字重回流。2026-09-30 对照用户“字体不要粗”的要求，将强调语义档先由 600 收敛到 500；模拟器目视仍偏重，因此继续收敛到常规 400。页面层级用字号、间距、颜色和位置表达；主操作仍可单独使用中等 500。
- 标注页“选区”类型选择改为应用内纸色面板。第一次模拟器实看确认普通视图确实被 2D 原生画布压住，故改为 `cover-view` 覆盖层。当前在 HUAWEI Mate 60 模拟器实际点选矩形、椭圆均可关闭面板并切换工具；照片上方主工具图标会同步显示当前形状，面板仅对当前项显示“当前”，不再把静态问题编号 1 误当成类型装饰。无绘制、无保存。热更新后 2D 画布短暂显示空底，模拟器重新载入后真实照片恢复；本次判为开发者工具热更新状态丢失，不能据此推断为用户重进后的图片加载故障，也不把热更新时空白截图当通过。下一步仍需用退出重进验证草稿照片与已存标注恢复。
- 本轮自动回归：非 PDF 本地服务集成范围 164/164 通过（排除 `tests/pdf-service-local-integration.test.cjs`，不代表 PDF 集成通过）；`node tests/local-compile.cjs` 的 WXML 26、WXSS 29 及 JS/JSON/原生模板检查通过；`git diff --check` 通过。真实下载照片的报告版式数据校验通过（离线，不调用 AI/云端/PDF；无真机验证）。
- 设备边界：iOS/Android 真机上的触控、安全区、系统授权、相机、语音和微信转发均未在本轮验证；UI体系当前完成的是统一基础规则与自动防回退，不等于所有页面的最终视觉验收。
- 本轮运行态复核：在开发者工具 HUAWEI Mate 60 模拟器的隔离 QA 记录中，现场记录与标注页均显示用户提供的真实装修照片；之前标注画布呈单色的现象本轮未复现，因此只记为“本次可见、根因未证”，不宣称已定位或修复。标注页复核发现顶部返回、工具栏返回和底部保存返回三处出口重复；现收敛为顶部离开决策、底部唯一保存主操作，并从工具栏移除重复出口。此项仍需在真机复核触控与窄屏比例。
- 现场记录页语音按钮的图标与按钮组居中，但两行文字组原先左对齐，造成文字视觉重心偏移；已改为文字组自身居中，并加入 UI 回归约束。录音按住／上滑取消实际手势尚待 iOS、Android 真机确认。
- 标注回显链路增加跨页面隔离联测：标注页保存导出图与编号标注后，现场记录页重读同一草稿，`displayImagePath` 指向带标注渲染图、标注数量与稳定 ID 均保留；实际真机页面仍需用用户测试照片复核最终像素呈现。
