## 二、功能说明

> 填「功能页面」或需要描述小程序用途的地方。

```
本小程序是面向装修与建材现场的巡查记录工具。

核心流程：按项目拍摄或上传现场照片 → 用语音或文字填写现场说明 → 在照片上圈选问题位置并自动编号 → 人工核对问题描述、区域、分类与责任方 → 确认后生成移动端在线巡查报告 → 通过微信转发单份只读报告给业主或施工方。

AI 为可选辅助：用户可自行选择是否使用「AI 识图」辅助整理问题描述与字段，识别结果一律标注为「待核对」，必须经用户核对确认后才会写入报告。不使用 AI 也可完整走完流程。

无需手机号登录，使用微信身份识别账号。
```

## 三、审核操作路径

> 这是审核员实际会照着走的路径。写清楚，能显著减少来回。

```
1. 打开小程序，欢迎页阅读《隐私与服务说明》并点击同意。

2. 项目页 → 点「新建项目」→ 填写项目名称后保存。

3. 进入项目详情 → 点「开始现场记录」。

4. 拍摄或从相册选择一张现场照片。
   （如无现场照片，相册中任意一张室内照片即可走通流程）

5. 在照片下方选择「仅手动填写」或「AI 识图」。
   - 仅手动填写：直接在输入框填写问题描述。
   - AI 识图：等待识别结果，结果会显示为「待核对」。

6. 点照片上的「标注」→ 在照片上框选一个区域 → 自动生成编号 1 → 点「保存标注并返回」。

7. 点底部主按钮进入「人工核对」→ 可编辑问题描述、区域、分类、责任方。

8. 点「确认内容并生成报告」→ 打开在线巡查报告。
   - 报告首屏可看到「巡查概览」与（如有严重/较重问题）「需要优先处理」清单。
   - 点清单中的「查看」可跳转到对应照片。

9. 在报告中点「转发这份报告」，可分享给微信联系人只读查看。

10. 个人信息权利申请入口：
    底部「我的」→「隐私与服务说明」→ 页面下方「个人信息权利申请」
    → 选择申请事项（如「注销账号」）→ 点「提交申请」。
    提交后页面显示「已受理，待核验」，并可在同页查看处理状态。
```

## 四、补充说明（重要，建议一并填写）

> 这几点是审核容易追问的地方，主动说明比被问再答省时间。

```
1. AI 为可选辅助功能，不替代人工判断。
   识别结果在界面上一律标注为「待核对 / AI 建议」，需用户确认后才进入报告。
   未识别到问题时，页面明确提示「不代表现场验收合格」，不会给出合格结论。

2. 账号注销与个人信息权利申请。
   入口：「我的」→「隐私与服务说明」→「个人信息权利申请」。
   申请提交后由运营者核验处理，用户可在同一页面查看处理状态。
   页面已明确告知：「已受理」不代表资料已删除或账号已注销。
   注销账号不会自动撤销已发布的报告分享链接，该规则已在页面写明。

3. 数据用途与第三方。
   照片、录音与标注仅用于巡查记录、AI 分析与报告生成。
   选择 AI 识图或语音转文字时，相关素材会发送至第三方服务处理；
   用户可选择完全手动填写，不触发任何第三方处理。
   详见小程序内《隐私与服务说明》。

4. 分享机制。
   报告通过不可猜测的分享令牌做只读访问，接收者无需登录、也看不到其他任何记录。
   作者可随时撤销分享链接。

5. 不涉及支付、不涉及直播、不涉及用户生成内容公开展示。
```

## 五、提审前自检

在点「提交审核」之前，用你自己的手机走一遍上面第三节的路径。

**重点确认这三件（都是我无法替你验证的）：**

```
□ 真机拍照 / 相册选图能正常回调
   —— 这是全流程的地基。此前只验证过开发者工具模拟器，
      而模拟器的文件选择器历史上出现过「选图未返回」。

□ AI 识图能真实返回结果
   —— 需要确认腾讯云额度充足。此前真实调用出现过 HTTP 402（额度耗尽）。

□ 提交一次个人信息权利申请，确认显示「已受理，待核验」
   —— 集合已建好并验证通过，但请用自己的账号再走一遍。
```

**另外两件准备：**

```
□ 腾讯云 SecretKey 已完成轮换
   —— 该密钥曾在截图明文暴露，一直未轮换。提审通过后会面对真实用户。

□ 上线前导出一次全量数据作为还原点
   —— 上线即产生无法重造的真实数据，目前没有任何备份。
```

## 六、审核被驳回时的应对

| 常见驳回原因 | 应对 |
|---|---|
| 服务类目与功能不符 | 核对类目是否覆盖「现场巡查记录 + AI 辅助整理 + 只读在线报告」 |
| 隐私指引与实际数据流不一致 | 按第四节的 3、4 条与后台隐私保护指引逐项对齐 |
| 未提供有效账号注销功能 | 指向第三节第 10 步的入口；若仍被质疑，需补自动处置能力而非仅受理 |
| 审核路径走不通 | 按第三节逐步复现，确认无死路；如有弹窗阻断需补充说明 |
| AI 生成内容未说明 | 引用第四节第 1 条 |
