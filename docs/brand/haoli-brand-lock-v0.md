# 毫厘智管 · 品牌锁定稿 v0

状态：v1、v2、v3 均已撤回；v8 为工作方向，已接入本地小程序和母版，待用户视觉验收。不作为商标注册、字体授权或印刷色彩证明。

## 产品定位

面向现场巡查人员，以照片、精确标注、人工核对和单份报告完成一次可复核的现场记录。项目只负责归属，不表达施工管理、任务管理或进度管理。

## 品牌符号 v1：已撤回

- 四个定位角：只圈定需要被看见的局部；不使用相机、尺子、对勾或施工帽等直白行业符号。
- 中央朱砂点：一处已经被标注、需要被确认的细节。
- 符号在小尺寸仍只保留两种信息：定位与落点。

撤回原因：四角框加标注点在实际预览中呈现为扫码框，过于工具化，不再用于任何正式页面。

## 品牌符号 v2：已撤回

- 用产品名中最有记忆点的「厘」作为应用图标，不再画行业工具。
- 以深松石底配纸白文字；不使用朱砂点、渐变或额外装饰。
- 产品名用「毫厘智管」原生文本呈现，保证不同设备上的中文可读与检索。

撤回原因：把单一汉字放进深色方块只是应用头像，不构成独立的品牌符号。

## 品牌符号 v3：已撤回

- 两道不闭合的深松石笔触围合一个朱砂落点，表达在复杂现场中留意并落定一个细节。
- 形态优先于行业隐喻；不出现相机、尺子、施工符号、扫码框、对勾或文字。
- 主符号透明底使用；名称「毫厘智管」以原生文字作为字标，形成“符号 + 字标”的完整 Logo。

撤回原因：笔触与落点有情绪，但缩小后更接近装饰插画，不能建立稳定、克制的产品识别。

## 品牌符号 v8：几何留隙（当前工作方向）

- 两块中性墨色平面保持同一方向、不相接触；中间是一块很窄的朱砂色平面。
- 两道纸白留隙是这个符号的主语：它表达“相差毫厘，也应被看见和复核”，而不是门、相机、尺子或工程构件。
- 采用平面构成，不加透视、阴影、渐变、金属或 3D 材质；小尺寸只保留纸白、墨色与朱砂三种既有界面颜色。
- 完整名称仍以原生文字「毫厘智管」呈现，符号只承担辨识，不取代产品名称。

### 产品标记与出具单位的边界

- 产品标记用于欢迎页、项目页、我的页，以及报告顶部和尾部的“毫厘智管”识别。
- 公司 LOGO、公司名称、巡查人和联系电话属于报告出具资料；它们从用户设置快照读取，出现在报告“出具单位”和“出具信息”中。
- 两者不能互相替代：没有公司 LOGO 时，不用产品标记假装公司标志；分享链接只展示单份报告和这份报告冻结的出具资料。

## 色彩角色

- 纸白 `#F5F1E9`：符号留白、温润阅读底色。
- 墨色 `#1C1A17`：标题、正文、图标与符号主体。
- 朱砂橙 `#E15D3A`：细微差异、标注落点和唯一主操作；不可扩展为页面底色。
- 不再使用深松石或墨绿色。品牌图形与正式界面共享同一套三色系统。
