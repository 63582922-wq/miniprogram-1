# report-pdf-service

Puppeteer PDF generation service for inspection reports.

Current template characteristics:

- dark formal report style
- grouped by photo, not duplicated per issue
- annotated image preferred
- multiple issues rendered on the right side of the same photo group
- footer page numbers generated by Puppeteer

## Start

```bash
cd report-pdf-service
npm install
npm start
```

Default port: `3100`

## Health Check

```bash
GET /health
```

## Generate PDF

```bash
POST /api/report-pdf/generate
Content-Type: application/json
```

## Mini Program Settings

Configure the following fields in the settings page:

- `PDF 生成引擎`: `puppeteer`
- `PDF 服务地址`: `http://127.0.0.1:3100`
